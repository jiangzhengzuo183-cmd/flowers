# 主菜单与正式剧情入口

Godot 4.7.2 / Compatibility。工程默认入口为 MainMenu.tscn，F5 打开主菜单；独立打开 VisualNovel.tscn 按 F6 仍直接进入剧情。主菜单使用 1920×1080、16:9，离开时恢复接入场景原有配置。

## 当前画面

纸叠较前版拉近，深暖木桌仅露窄边；主纸轻斜约 0.8°、边缘较平直，保留淡点阵。下层白纸、原黄色纸及额外蓝纸角独立错相抽帧。标题与中文菜单整体下移 28px，尺寸与排版层级保持。英文标题逐字浮现后持续手绘抖动，中文使用深褐稚拙手写字体。

纸面保留五处连续、不规则的边缘啃痕，每处由三到四口重叠构成；另外两处在缺口附近内侧加入小型闭合齿痕圈。真实透明遮罩同时切去上层纸、对应纸影及纸面印迹；洞中露出下层连续英文手写页、纸纤维边和内投影。运行中生成的相交纸洞仍合并，不出现内部白缝。

左下只放一朵放大的蓝色油画棒花，延续现有花头图集、逐笔绘制和常态抖动。铅笔和三个人头像已撤下。四周采用中性灰黑暗角，覆盖较广、边界比最初更清楚，中央菜单保持明亮；暗角不拦截点击，便利贴与指针位于其上方。

## 老鼠与声音

老鼠保留用户选定原图的脸、耳朵、胡须、身体肌理和尾巴。去小爪资源只覆盖四个局部区域，其他区域继续直接采样原图，避免重新绘图改变角色或引入透明底雾边。尾巴持续局部摆动，身体保持手绘抽帧，阴影同步变形；跟随位置与 360° 转向每帧更新。

指针静止 1.5 秒且老鼠停稳后开始啃纸。四次啃咬逐渐扩大随机洞口，移动立即打断；弹窗期间不啃，离开主菜单清空。最多八处交互纸洞，初始边缘痕迹不占其容量。

主菜单复用既有 bakery.ogg（Calm theme / pebonius / CC0），低音量循环、淡入；其原曲开头有短暂安静引子。菜单使用独立流副本，不改变剧情音乐资源。制作名单及退出提示略压低背景音乐，关闭恢复；进入剧情或退出时淡出并释放。桌面版自动播放，Web 等待首次键鼠输入。

移动沙沙声及每口啃纸声复用 paper.mp3（Luckius / CC0），啃声与真实 gnaw_bite 信号一一对应，短音粒有细微音高差。停止啃咬、失焦、弹窗或离开场景时停止。音乐和音效读取已有 experience-audio.cfg 的音量／静音偏好，保留全局总音量。授权记录见 visual_novel/assets/audio/LICENSE-SOURCES.md。

## 交互与文件

- 开始游戏：短淡出进入 res://modules/visual_novel/VisualNovel.tscn，保留 game_entry / start_requested 接口。
- 制作名单：中央奶黄色便利贴、折角、背景变暗；返回、Esc 或遮罩揭开退出。
- 回到桌面：沿用迷宫风格二次确认，确认后正常关闭程序。
- 主菜单首帧即使用已有三帧黄色指针，离开后交回原剧情／游戏指针。

## 实际验证与边界

- check_main_menu.gd：196 项，四种物理尺寸、固定 16:9、纸层、鼠标、弹窗、正式剧情和原三个迷宫接入。
- check_paper_details.gd：21 项，花朵绘制、相交洞口、连续笔记、纸面印迹裁切及实时阴影。
- check_menu_decor.gd：20 项，减量边缘啃痕、内侧齿痕圈、左下大花、四处去爪与其余原图保持、暗角像素和点击层级。
- check_menu_audio.gd：11 项，1.5 秒边界、四口同步、真实音频混音波形、弹窗音量及退出释放。
- check_cold_start.ps1：不替换 SceneTree 的真实默认入口首帧及连续 200 帧，防止 F5 初始化时序回归。
- check_quit.gd：实际点击退出、取消、再次退出及确认关闭。
