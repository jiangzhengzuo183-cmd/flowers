# 剪贴画加载界面

Godot 4.7.2 / Compatibility，独立组件。最终顺序：**花束 → 思考 → 低头阅读 → 花束**。三张用户 PNG 原样复制，两个工程的六份副本均已通过 SHA-256 比对；没有重绘、抠图或覆盖源文件。

## 在 Godot 中查看

打开本目录的 `LoadingPreview.tscn`，按 F6。预览持续循环，便于检查全部姿态；实际加载完成后会退出，不强制等待整轮动画。F5 保持工程原有入口。

## 本目录

- `loading_screen.gd`：纯白全屏、单个 TextureRect 原子替换人物、10 FPS 抽帧抖动与轻微弹跳。每次姿态随机约 1.2–1.8 秒；切换约 0.2 秒。米黄色纸边及原图纹理全部保留。
- `scene_loader.gd`：后台请求 PackedScene、轮询加载状态、场景切换、防重复请求、结束淡出及资源清理。
- `LoadingPreview.tscn`：独立循环预览，不包含目标游戏场景。
- `assets/charlie_bouquet.png`、`charlie_thinking.png`、`charlie_reading.png`：三张原始附件，未修改图片字节。

复用既有 YeLiHangJiuLinKaTong.ttf 手写字体；字体位置见脚本 HAND 常量，两个工程分别指向各自原有资源，没有新增字体。文字颜色 #705039，42px / 1080 设计高度，无描边、发光和阴影；省略号每 0.25 秒按 0→1→2→3→2→1→0 循环。

使用原图 alpha 使用区域建立 AtlasTexture，仅忽略透明画布留白，不裁掉纸边或修改原图。显示高度为视口的 42%，宽高比不变；中心在屏幕 (50%,45%)，文字置于人物下方。加载期间临时使用 EXPAND 铺满 16:10，结束恢复场景原有适配方式，不永久改变工程配置。

## 接入接口

宿主接入顺序：`begin(tree, self)` → `await fetch(screen, scene_path)` → 使用原有宿主实例化并挂载 PackedScene → `await finish(screen)`。原有事件、布局及游戏逻辑保留。独立场景跳转使用 `await change_scene(tree, path)`。

加载层挂在根窗口，生命周期独立于目标场景；普通宿主退出时会释放其加载层。后台加载失败时返回 null，保留原场景并结束遮罩，控制台记录实际错误。使用工程级锁避免同时创建多个加载层。每次加载至少展示 3.0 秒（Inspector 可调 2–4 秒），淡入 0.18 秒、淡出 0.24 秒。资源读取与展示等待并行，等待展示时间结束后才实例化目标场景，避免迷宫计时提前运行。快速跳转实测约 3.27–3.30 秒；资源实际加载超过 4 秒时仍等到完成。

资源文件通过 ResourceLoader 后台加载；原项目中程序生成的 3D 场景仍需要在主线程完成节点初始化。组件监听节点加入，在这些同步搭建步骤间继续提交人物和文字的绘制，不改写迷宫生成器。此机制参考 [Godot RenderingServer.force_draw 文档](https://docs.godotengine.org/en/stable/classes/class_renderingserver.html#class-renderingserver-method-force-draw)，只在主线程调用。
