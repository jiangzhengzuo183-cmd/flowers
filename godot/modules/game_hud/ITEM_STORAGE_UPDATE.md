## 道具容量与使用规则

**整个背包最多三件。所有可存道具共用三个物理格子；同类也一件一格，不叠加出隐藏数量，没有额外钥匙仓库。**

- 幸运兔脚、巧克力蛋糕、粉色药丸、钱币和马蹄铁都计入三件上限。
- 满包时先拒绝拾取，不播放吸走消失动画。道具仍留在地面，释放容量后可再正常拾取；站在范围内释放容量也能继续领取。
- 数字1/2/3选择当前第1/2/3格，格子不是固定绑定某一种道具。使用后只清空对应格子，其他物品不自动移位。
- E主动使用选中兔脚、蛋糕或药丸；保留原Q和双击的使用兼容。按住E的重复键事件不会连续消耗。
- 门前E优先进行原钥匙解锁，消耗对应一枚钱币/马蹄铁。选中的蛋糕不同时触发；缺钥匙或门已开启时也不误用蛋糕。
- Maze03圣堂附近E仍优先激活圣堂；不新增Maze03道具玩法。

巧克力蛋糕ID：ChocolateCake。拾取只存入背包；主动使用后调用原统一体力接口恢复45，保留1.3倍加速8秒和原黄色线条拖尾。再次使用刷新时限，不叠加倍率。

粉色药丸ID：PinkCapsule。拾取只存入背包，主动使用时才按原80%/20%概率调用全局透视7秒或减速4秒；原视觉、音效和效果结束清理保留。

幸运兔脚/钱币/马蹄铁ID仍为LuckyRabbitFoot / LuckyCoin / LuckyHorseshoe。门的对应关系和消耗规则不变。面粉仍是原即时惩罚，未改为可存道具。

背包快照现为三个物理槽条目；quantity(id)由这三个槽统计，无独立超额计数。can_accept_pickup在开始拾取前判断容量，grant再作一次校验。状态和通知仍由原效果数据驱动；重开清空物品、选择和效果。

- E实际生成兔脚原寻路光团；Maze03圣堂E保留。
- 重开清空背包、选择及蛋糕/药丸状态。
