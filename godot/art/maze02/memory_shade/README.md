## 使用

- `MemoryShade.tscn` 是完整效果角色，实例化到场景即可使用。
- `GhostPreview.tscn` 打开后按 F6。1/2/3/4 切换待机、行走、观察、啜泣，拖动旋转，滚轮缩放，B 切换背景，P 切换粒子。
- `Ghost_MemoryShade_Modified.glb` 是独立模型。完整动态、手臂／衣物避让与柔光需要配套 Godot 场景。
- 根节点为脚底放置锚点，局部 +Z 向前。源模型约 1 单位高，脚底已在包装层归零并留 0.012 悬浮余量。

## 最后确认的设计

保留原头顶、头发主体、原袖型与宽衣摆，只收小袖口。手臂恢复自然姿态，运行时只允许最多 6° 的小幅修正。

统一冰蓝色，渐变只改变透明度，不使用深浅色带。身体基础 Alpha 0.24，头发约 0.38，衣服从下缘约 0.32 平滑过渡到上部约 0.48，视角边缘最多额外增加 0.035。腿脚始终完整。

袖口是原网格上的局部整形，共调整 555 个原顶点，并更新邻近法线。无袖尝试和衣服侧边整体收窄均已撤回。原 UV、骨骼索引与蒙皮权重保留。

衣摆使用小幅多相位 Shader 摆动，默认幅度 0.014；头发约 0.0015。悬浮幅度 ±0.006，呼吸亮度 ±2.5%。局部多层柔光使用相同网格，不改变全局环境。

18 个稀疏环绕微光持续存在。动作时左右手各最多增加 5 个粒子，生命 0.75 秒，脚边／转身最多 10 个，生命 1 秒。它们跟随真实骨骼及角色运动触发，停下后停止发射并自然淡去。

## 限制

原模型的头发、身体和服装共享网格，材质层次由柔和区域遮罩估计。袖口、头发与衣摆没有独立布料骨骼，动态采用 Shader 形变。

衣物接近前臂或手掌时，在 Godot Shader 中局部让开。该处理是针对本角色的近似避让，并非完整布料碰撞，也未烘焙进 GLB。单独 GLB 在普通查看器中仍可能出现透明叠层排序。完整效果请使用 MemoryShade.tscn。

当前资源保持独立，正式 Maze02 场景未接入该角色。
