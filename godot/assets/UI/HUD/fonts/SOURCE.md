# HUD handwritten typeface

Derived subset of Xiaolai Regular v3.126, renamed Algernon HUD Hand. Source: https://github.com/lxgw/kose-font/releases/tag/v3.126 . SIL OFL 1.1; full original license and copyright are in OFL.txt. Glyph outlines unchanged; only included characters and font family names are changed. Existing Source Han Sans remains the fallback for future text.

Build: node tools/build-hud-font.cjs, using fonteditor-core in the ignored .tools folder. No runtime dependency is added.
