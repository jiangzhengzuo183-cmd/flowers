共24张slices：11数字/冒号、3闪电、3圆槽、2菜单、5道具紧边界图标。全部原图为RGBA、角落透明，无整张白底。透明连通区域拆分保留原RGBA和抗锯齿边缘；不重绘、不改色、不拉伸。可用tools/import-hud-assets.ps1重建。

Godot导入：无损、保留Alpha、fix_alpha_border=true、无mipmap；显示线性过滤及等比缩放。数字不重复增加描边。

指南针原图虽合并，compass.gdshader可在显示时分离指针和黄色圆弧，根据查理真实朝向平滑旋转，无需覆盖原图。sticker_finish.gdshaderinc只在运行时轻微软化外露白边，并加很淡接触影；原PNG字节保持不变。

计时底图按用户确认留透明；后续用户取消了右上设置，不再使用设置占位，音乐设置保留ESC。章节任务取消背景及描边。面粉、电视、屏障、圣堂没有独立状态PNG，以真实状态文字及剩余时间显示。

字体：fonts/HUDHand.ttf为小赖Xiaolai Regular v3.126派生子集Algernon HUD Hand，圆润稚拙手写风格；SIL OFL许可见fonts/OFL.txt，来源见fonts/SOURCE.md。原数字PNG保持不变。E键帽、通知圆角条及便利贴确认框由Godot原生控件绘制，不生成替代PNG。

三个物理背包槽共用LuckyRabbitFoot / ChocolateCake / PinkCapsule / LuckyCoin / LuckyHorseshoe，最多三件、同类一件一格。蛋糕与药丸按用户新要求改为存储后主动使用，原效果内容不变。指南针圆盘主体与计时和菜单共用40像素顶部对齐线，突出纸签允许向上超出12像素。

最新修订：指南针新增4个派生图层（原图保留），指针与黄弧独立旋转，清理纸底残影及外缘碎点，白边收细。使用compass_regions.gd记录裁切位置。体力改为较细白边，其他PNG不变。章节统一第一章，计时240×64且与右上菜单一起下移16像素；通知中下居中，交互提示定位到实际门/立方体旁。详见modules/game_hud/VISUAL_POLISH_UPDATE.md。
