# 手绘黄色鼠标｜独立三帧抖动素材包

这是游戏当前使用的放大版鼠标：透明 PNG、白边黄色箭头、轻微抽帧式线条抖动。无需下载迷宫工程。

## 包含什么

- source/original.png：用户提供的原始 1254×1254 PNG，未覆盖或重绘。
- cursor/frames/frame_0.png、frame_1.png、frame_2.png：三张独立透明底 PNG，画布 80×92，可见图案高约 84px。
- cursor/hand_drawn_cursor.gd：独立 Godot 4 播放脚本。
- cursor/HandDrawnCursor.tscn：可用于单个场景的节点组件。
- cursor.json：帧顺序、时长、尺寸、热点及文件校验信息，便于其他引擎接入。
- project.godot、Demo.tscn：独立预览工程。

## 先看效果

解压后，在 Godot 项目管理器「导入」本包的 project.godot，打开后按 F5。移动鼠标，或悬停在中间按钮上，即可看到三帧抖动。使用本机 Godot 4.7.2 Compatibility 验证。

## 接入自己的 Godot 工程（推荐全局使用）

1. 将本包整个 cursor 文件夹复制到自己的 Godot 工程中，例如 res://cursor/。
2. 在项目设置中将 cursor/hand_drawn_cursor.gd 加入 Autoload（自动加载），名称可用 HandDrawnCursor。
3. 运行游戏即可；不需要复制本包的 project.godot、Demo.tscn 或任何迷宫文件。

脚本使用相对资源路径，cursor 文件夹可以整体改名或移动。自动加载后跨场景保留；游戏暂停时仍能播放。仅需要单个场景时，也可以把 HandDrawnCursor.tscn 拖入该场景；它离开场景时恢复系统鼠标。

接入时让本组件成为唯一的鼠标动画控制器。它替换普通箭头和可点击手形，不改变系统鼠标位置、点击热区、鼠标捕获方式或视角控制。游戏将鼠标设为隐藏／捕获时，组件暂停更新；恢复可见后继续播放。

## 三帧抖动参数

- 播放顺序：0 → 1 → 2 → 0，循环。
- 帧率：8 fps，每帧 125ms，一轮 375ms。
- 点击热点：每帧固定为 (7,6)，以 80×92 画布左上角为原点。
- 三帧点击尖端附近的像素保持一致；主要是箭头后部约半像素的轻微形变，鼠标指向位置不会跳动。
- 脚本的 frames_per_second 和 hotspot 可在自动加载脚本／组件中调整。若改变图片尺寸，需同比调整热点；保持当前尺寸时直接使用默认值。

其他引擎可直接读取三张 PNG 和 cursor.json，按上述参数播放，无需 Godot 脚本。

原始图片和三张游戏帧均按原字节复制。该独立包不依赖 HUD、玩家、道具、计时器或迷宫脚本。

## 已完成的独立验证

独立预览工程 16 项、将 cursor 文件夹改名并移到 widgets/stickers 后 16 项，均通过。检查包含三帧原生鼠标播放、缓存资源与固定热点、暂停仍播放、鼠标捕获时保持隐藏，以及重复实例保护。原图和三张 PNG 与游戏中的源文件逐字节一致。
