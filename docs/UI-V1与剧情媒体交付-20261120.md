# UI V1 与剧情媒体交付 · 2026-11-20

修改直接应用于 `flowers-team-chapter1`，保留上一轮改动，没有提交、推送、合并或发布。此记录补充并更新上一轮 UI 修正交付。

## 剧情调整

- 第一次墨迹测试：实验对白读完后自动进入现成的四卡交互，不再要求寻找独立入口；结束后接回查理观察墨迹的原对白。再次观察仍可通过已有入口进行，观察完成数据复用原状态机。
- 第二次墨迹测试：保留查理误会、尼姆说明的剧情；听完教授说明后，自动进入卡片交互。
- 酒馆：读完“查理开始跳舞，大家哄笑起来”后播放用户提供的原始 MP4。视频为1280×720，时长约5.09秒，约7.64MB。自然结束或点击跳过都接回乔的下一句对白；重复结束事件不重复推进。播放期间暂停原背景音乐，返回剧情后恢复。
- 实验室探索：尼姆教授站在右侧通道，可直接点击立绘交谈。移除记录纸、墙上迷宫图和笼中阿尔吉侬的探索入口，不删除实际迷宫玩法。
- 移除“写着动机的记录纸”互动页面，保留手术决定、风险告知和进步报告的主线。

## UI 调整

- 沿用现有1600×900内部画布，以1.2倍映射1920×1080规范；新增共用设计变量，避免更改整个游戏坐标系统。
- 地点、功能按钮以64px安全边距布局；对话框对应规范的X=64、Y=802、1792×214。姓名标签与正文共用X=128阅读轴。
- 使用用户新纸样作为HUD背景；仅在渲染时取有效区域，不重绘或覆盖原图。阅读模式显示地点横条，探索模式显示任务，沿用折叠、新目标提示及完成反馈。
- 使用用户提供的报告、设置、返回/重启图标；返回/重启组合图按两个图标分别使用。保留对话记录入口，帮助入口移至设置中。
- 设置面板改为紧凑的三组音量行、阅读速度、静音、帮助及返回按钮；打开时在内容排版结束后居中，避免超出屏幕。
- 对话正文保持约28.8px，不通过缩字容纳长对白；每页最多三行，过长时分页，分页保留原文，不改动剧情历史。
- 双人中心参考规范位置，独白居中；减轻未说话人物的暗化。夹子沿用原图与大小，跨住白纸左上边缘，避开姓名文字。

## 运行与再次导出

双击项目根目录`启动游戏.cmd`后，浏览器打开`http://127.0.0.1:5180/`。

之后重新导出时，使用：

```powershell
powershell -ExecutionPolicy Bypass -File scripts/export-story-web.ps1
```

如果直接从Godot编辑器导出，还需运行`node scripts/package-story-media.mjs`，将原始MP4与播放器脚本复制到导出目录。发布时使用完整的`godot/exports/web/`目录。
