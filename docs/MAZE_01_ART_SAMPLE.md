# Maze 01 美术样板

## 清亮天光、水庭与石质收边

按 **F5** 进入正式迷宫。入口拱门、东北桥洞与南露台转角有局部暖光。西北水庭的暖光来自两团萤火和一处沉在水下的柔光。地上另有四团萤火，分别在东庭短高台、南侧抬高通路、东北桥北端和出口。每团有五个暖黄光点与一盏短距离补光。普通墙顶、教堂窗台与阶梯有细倒角，八处拱门沿用原轮廓，教堂和露台的大块拼缝更清楚。

水面标高 `-0.31 m`，池底标高 `-0.60 m`，最大深度约 29 厘米。慢走产生涟漪，跑步、涉水起跳和落回水面会产生短暂水滴。水庭、暖光与石质收边由 `godot/art/maze01/` 内独立脚本控制。几何收边用于渲染，沿用现有通行碰撞。实机检查可在右下选择「西北庭院入口」「南露台 H4」与「教堂南门 G8」。

## 成品光影 · 暖拱门与蓝紫阴影

从原 Godot 工程按 **F5** 进入，右下「查看关卡位置」可选「南露台 H4」「教堂南门 G8」「中心圆形教堂」或「教堂外观总览」。普通通道、南露台和室内均使用 `#DDD1BC` 浅米石地。地面只通过两张可平铺的凹凸和粗糙度贴图表现细磨砂，门厅与露台有少量浅缝。奶油白墙和栏杆通过收边、墙脚及受光分层。教堂壁柱、窗沿和檐口用同色系细磨石，尖顶和四扇升降门共用湖水青蓝 `#64A9A8`。

蓝紫补光建立墙侧冷影，主光略暖，教堂南拱门和吊灯提供局部暖光。外围两层低速云海、微弱星点和低频流星独立于建筑。西北水面增加短暂脚步涟漪，西侧星龛沿用原星星、光效与音阶。出口使用浅色石质嵌环标记舞蹈位置。新增细节均为视觉表现，艺术测试比对原有网格和碰撞，三次迷宫共享空间及触发条件。

地面贴图位于 `godot/art/maze01/materials/limestone/`。材质绑定与局部氛围分别由 `maze01_dream_finish.gd` 和 `maze01_atmosphere.gd` 管理。验收视角包含 `.verification/maze01-finished-art/` 下的全景、南露台、教堂室内、机关开启和星龛回廊。

## V2.1 · 正式迷宫

原 Godot 工程按 **F5** 进入全图上材质的正式 Maze 01。右下角“查看关卡位置”可选择中央教堂、西北下沉花庭或入口教学门。入口教学门旁靠近 S1 按 **E** 可看到 D1 点亮、上升与收纳。旧局部样板仍可从原样板入口打开。

### 资源检查与覆盖

- 迷宫由 `maze_01.json` 与灰模布局数据程序生成。四扇门原本就有固定门框、独立的 `MovingGate` 门板、门杆和 `GateCollision`。本轮直接复用。
- 可复用的建筑资源有石膏的程序法线噪声、湖蓝釉面材质、青蓝玻璃和天空渐变 Shader。查理与电视资产的位图是各自模型专用的颜色贴图。本轮复用法线噪声和现有 Shader，无外部贴图下载。
- 暖白墙与栏杆延用样板石膏，浅米地面恢复已选中的 `#DDD1BC`。全图普通通道、H1–H4 桥面与踏步、H5 下沉花庭、H6 石廊和教堂地面均已绑定。花庭和教堂用同色浅拼缝。19 件屋顶共用原湖蓝材质，五块玻璃调成浅青蓝半透明。
- 主光保留样板的方向（俯角 46°、朝向 −32°），颜色偏中性，强度 0.21，阴影不透明度 0.39。淡粉紫补光 0.50，环境遮蔽强度 0.17，关闭全局 Bloom。沿用静态天空 Shader，颜色改为清透蓝紫、饱满粉紫和奶油粉白，俯视保留蓝紫渐变。
- 紫釉门板使用沿现有门杆与横梁分布的细嵌线。开启时中央先亮、光沿横梁展开，门框随后提亮。总开启时间 0.65 秒，其中 0.14 秒蓄光；原门板向上移动 2.85 米，升完才解除碰撞。门框上方的收纳饰面仅是视觉部件。重置及运行初始开门状态同时更新发光状态。

## 第二轮 · 局部样板记录

沿用原样板入口。底部地面菜单可在教堂全景、人物试玩和室内灯光三个视角即时切换。三种颜色只应用于教堂室内、附近庭院的测试铺面，以及 H2/H4 的踏面；桥面侧边和样板栏杆统一使用暖白石膏。

| 地面 | 同镜头实拍结论 |
| --- | --- |
| 清亮鸢尾蓝紫 `#B1ACE0` | 当前默认。与暖白墙的色块分界最明确，湖蓝屋顶和查理的深蓝衣服依然容易辨认。 |
| 浅雾紫蓝 `#C0C6E5` | 更轻、更柔和，人物对比清晰；远景中铺面和浅墙的分界更弱。 |
| 浅米石 `#DDD1BC` | 更暖，衬得屋顶更青；从远处看，地面容易和暖白墙连成一片。 |

背景是全向的浅蓝紫、柔粉紫与奶油粉白渐变，俯视时仍能看到紫粉色，云层保持稀疏。照明使用中性偏暖白的主光（0.23）、淡紫补光（0.53）、较柔的阴影（0.39），关闭全局 Bloom。样板沿用湖蓝屋顶 `#64A9A8`，降低釉面反光，统一 D2、D4 门杆为柔珊瑚色。浅青蓝窗面、暖白窗框和现有檐口通过材质区分，地面三版共用同一套细颗粒与浅拼缝。

Windows 本机以 Godot 4.7.2 Compatibility 原生运行并截图。实拍位于 `.verification/art-sample-round2/`，包括远景 `06_global_pink_background.png`、人物 `02_player_view.png`、室内 `03_interior.png`、东西两侧教堂近景，以及三组 `floor_*_player.png` 和 `floor_*_overview.png`。自动检查通过 2686 项原网格和碰撞比对，覆盖跑跳、落地、开门、出口与重置。第二轮网页版本尚未导出或验收。

## 根据新参考调整

- 墙体向参考图的暖奶油黄靠近，受光面温暖，背光带柔和蓝紫；无砖缝、裂纹、污渍或黑描边。
- 背景覆盖完整球面：淡紫、浅粉、暖黄三段柔和渐变，包括低头、俯视和地图外围看到的下半球；上下均有少量静态柔云。按用户最后反馈，撤下高饱和版本，关闭饱和度/对比度增强，不用灰雾压低色彩。
- 紫粉主要体现在背景和适量环境光；主方向光保持暖白，湖蓝屋顶仍保持青蓝色。
- 为保证通透明亮，当前样板关闭全局 Glow/Bloom；灯泡保留自发光。主光 0.38、环境补光 0.36、阴影不透明度 0.40，环境遮蔽强度 0.40，避免强烈明暗和大面积泛白。

## 本轮范围

中央圆形教堂全部可见外墙、壁柱、窗框、尖顶、门廊平顶及室内地面；中央邻近部分普通墙；G4/G6/G7/G8 拱门；H2 普通桥段青灰蓝栏杆、H3 观景短台淡紫栏杆、H4 主要转折暖黄栏杆；D2 珊瑚橘、D4 湖蓝门杆；三盏几何吊灯，其中只有中心一盏具有真实无阴影局部光源。

教堂使用独立暖奶油石膏材质，带低强度 256×256 程序法线颗粒；程序网格通过世界三向投射使用该纹理。所有选定屋顶统一使用 #64A9A8，粗糙度 0.34、非金属，保留轻微釉面高光。雾蓝地面主要为教堂和邻近庭院的纯视觉铺面；原碰撞完全保留。

窗面采用低成本 Alpha 玻璃和少量高光条，部分窗面用暖黄色自发光示意灯火。原窗后仍是实体墙，没有挖窗或修改教堂结构，不能透视室内。细结构线仅放在样板拱门前缘，原教堂已有的壁柱、檐口和屋顶分割继续复用。

青色检查点圆盘及悬浮制作标记仅在样板中隐藏，原坐标与通关数据保留。其余墙、地面、门和桥段保留原灰模；H5 没有新增水面。H6 三个壁龛、干燥长廊及调查锚点不改。

## 资源组织与接口

```text
godot/scenes/art_samples/Maze01_ArtSample.tscn
  └─ 继承原 Maze01_Base，覆盖生成器与样板展示脚本
godot/scripts/art_samples/
  ├─ sample_generator.gd     原生成器 build 完成后绑定局部材质
  └─ sample_scene.gd         环境、样板观察按钮、成对透明材质适配
godot/art/maze01/
  ├─ materials/             石膏、屋顶、地面、玻璃与细线材质
  ├─ sample_palette.gd      按构件角色与明确区域分配颜色
  ├─ plaster_fade.gdshader  同色同颗粒的墙体半透明材质
  └─ legacy_prism_finish.gdshader
godot/art/environments/
  ├─ dream_sky.gdshader     全球面紫粉渐变与少量解析柔云
  ├─ dream_pink.tres        独立 Environment
  ├─ dream_lighting.gd     独立灯光预设类型
  └─ maze01_dream_lighting.tres
godot/data/art_samples/sample_run.tres
godot/tests/art_samples/check_art_sample.gd
```

建筑材质与环境资源独立。后续可以更换环境和灯光预设，不重新生成三套建筑。样板使用一个启用阴影的 DirectionalLight3D 和独立环境补光；原 SoftFill 仅在样板实例中隐藏。

原视线遮挡脚本不改：九条检测线、85% 遮挡阈值、22% 透明度、建筑不透明和物理层约定全部保留。材质在遮挡注册前绑定；样板注册后的石膏透明替代材质使用同色及同一颗粒纹理，避免变回旧灰色。

部分旧棱柱网格具有向外法线与反向正面绕序。样板桥面和栏杆材质在 Shader 中补偿背面受光翻转，不改变网格顶点、索引或碰撞。其他区域仍保持原样。
