# 纸艺 UI 与设置系统交付

本轮以 Godot 原生版为交付与验证目标，不再新增网页适配。打开 `godot/project.godot`，按 F5 运行。此前其他任务进行中的报告、墨迹接入改动保留；本轮没有修改剧情文本、节点顺序或对话推进条件。

## 界面与交互

- 右上 `PaperToolbar` 为右侧锚定的 HBoxContainer，只保留 `DialogueButton`、`BookButton`、`SettingsButton`，继续调用已有对话记录、进步报告和设置功能。自动播放、重新开始的右上控件移除，底层 `set_automatic()`、原重读确认与其他调用保留。
- 三张透明 PNG 原样复制，没有重绘或添加白色卡片。TextureRect 使用原色；单独边缘 Shader 清理透明轮廓的细薄彩色残留，保留原暖褐色轮廓。用户原图文件没有被覆盖。
- 图标按左上纸条的实际视觉中心动态对齐；固定点击区不随动效变形。齿轮由 88×88 调整为 76×76 设计像素，HBox 间距由 18 调整为 10，点击区宽度由 112 收紧为 104。
- 悬停 150ms 内放大到 1.08、倾斜约 2°～2.5°；移出平滑恢复。点击 240ms 内依次 0.92 → 1.04 → 1.0。快速移入移出会取消上一段 Tween，不累计位移或缩放。
- `PaperSettings` 是独立 Control 弹层，内有奶油纸纹面板、暖褐轮廓、麦芽黄色滑条与灰蓝辅助文字。关闭按钮、完成按钮、Esc 和面板外点击均可关闭；关闭时恢复焦点。打开期间逐字显示和主线输入暂停，不重置当前台词。

## 设置功能

| 设置 | 实际接入 |
|---|---|
| 主音量 | AudioServer 的 Master 总线 |
| 背景音乐 | VNMusic → Master；现有 BGM 播放器使用 VNMusic |
| 音效 | VNEffects → Master；脚步、纸张声与房间机器使用 VNEffects |
| 静音 | Master 总线静音；恢复默认可解除 |
| 窗口／全屏 | DisplayServer 原生窗口模式 |
| 自动适配／16:9 | 保留项目原有等比 1600×900 画布适配 |
| 16:10 | 1600×1000 显示区域，1600×900 剧情居中留白，不拉伸或裁切；退出视觉小说恢复其他模块原画布 |
| 文字速度 | 原逐字显示速率的 0.55／1.0／1.65 倍，继续使用原来的点击、Enter、空格、方向键推进 |
| 恢复默认 | 简短确认后恢复音量、静音、窗口、比例和文字速度 |

设置实时写入 `user://vn-settings.cfg`，只存偏好、不保存或改写剧情状态。首次使用兼容原 `experience-audio.cfg` 音量。原播放器的音量乘数移到总线，避免重复衰减；播放器的场景淡入淡出和机器旋钮本身的音量仍保留。
