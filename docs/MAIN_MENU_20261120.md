## 本轮最终画面

- 保持 1920×1080、16:9。纸叠相对桌面拉近，桌面露出约为此前缩小纸叠版本的一半；上层纸轻斜、边缘平整，保留淡点阵及独立纸层微动。
- 标题及中文菜单整体下移 28px。左下使用一朵放大的蓝色油画棒花，撤下铅笔与三个人头像。
- 五处连续不规则边缘缺口，以及两处相邻的小闭合齿痕圈。遮罩实际切透主纸与对应投影，露出下层英文笔记、纤维白边及内阴影；数量已按反馈减少。
- 中性灰黑暗角，覆盖较广、过渡边界明确，中央保持清楚。便利贴、退出框及指针不受暗角压暗，不影响点击。
- 老鼠只移除四只小爪；四处局部之外继续使用原图，脸、耳朵、胡须、身体肌理和尾巴保持。尾巴持续局部摆动，接触阴影同步。

## 行为和声音

老鼠停留 1.5 秒、停稳后开始啃纸；四口逐次扩大纸洞，移动立即停止。原有连续跟随、360° 转向和纸面沙沙声保留。初始缺口不占八处交互纸洞容量。

主界面复用项目授权的 Calm theme（pebonius / bakery.ogg / CC0），低音量循环淡入，保留曲首安静引子。制作名单、退出框略压低音乐，返回恢复；进入正式剧情及退出时淡出释放。每口啃纸对应一段短纸张录音（Luckius / paper.mp3 / CC0），带细微音高差，停止或失焦即收声。读取已有音量与静音偏好，不覆盖其他模块配置。桌面版进入菜单即播放，Web 按浏览器要求等待首次键鼠输入。

开始游戏仍进入朋友的 VisualNovel.tscn；制作名单仍为带折角的中央便利贴；回到桌面仍需二次确认。三个迷宫的核心机制与 HUD 均未改动。
