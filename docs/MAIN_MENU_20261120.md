# 主菜单交付记录（2026-11-20）

分支：codex/main-menu-paper-20261119。审核：[PR #5](https://github.com/jiangzhengzuo183-cmd/flowers/pull/5)，未合并主分支。

## 本轮结果

主菜单保持 1920×1080、16:9 全屏。主纸居中等比放大，标题和中文字保留原来的位置与大小。深暖木桌只在窄边和局部边角出现；左侧下层纸稍内收，多露出一点桌面。后续微调将下层白纸上沿收回约 4px，补回顶部木纹，保留底边和蓝纸小角，主纸及文字位置不变。原有黄色纸层继续留在右下，蓝纸是额外的一张，只在左下露出小角。

纸层缺口已改为完整下层纸张交叠：每张独立错相微动，内部不做三角硬裁切。纸边保持连续，纸与纸之间有窄阴影，纸叠在木桌上有更柔和、较深的投影。主纸淡点阵保留；胶带、手部、查理插画、光斑和半屏明暗均已移除。

英文手绘标题逐字原位浮现、持续轻抖；中文为深褐稚拙手写体。三组八朵蓝／青色花头分批绘出并微动，无茎叶。花、标题和中文共用主纸遮罩，啃穿时同处印迹一起缺失。

老鼠连续跟随与 360° 弧线转向，脚步、速度和转弯驱动贴身接触阴影。3 秒静止后四次啃咬生成独立随机破口；相交洞口连续，没有内部白缝，边缘有纸纤维、厚度和内阴影，下面是连续英文斜体手写笔记。

铅笔在左下竖放，笔尖略朝菜单倾约 12°，加粗笔杆延伸到屏幕下方以外。铅笔有紧贴纸面的接触阴影及柔投影。老鼠真正横跨时轻收身 0.08 秒、腾空 0.56 秒、高度约 42px，再轻微落地回弹；阴影保持在纸面并随离地变化。双向跨越都可触发，平行经过不会误跳，同次跨越不会连跳。铅笔和完整纸洞外缘范围禁啃，鼻尖也参与检查，打开面板时不会悬停半空。

主菜单从首帧使用既有三帧黄色指针，弹窗内保持同款。制作名单沿用中央奶黄便利贴、折角、变暗与揭开退出。回到桌面沿用迷宫风格确认框。开始游戏进入正式视觉小说，而非迷宫选择。

## 修改范围和接口

- main_menu.gd：独立木桌、完整纸叠、花朵、铅笔、菜单指针接入，保留正式剧情接口。
- paper_stack.gd / paper_layer.gdshader / paper_motion.gdshaderinc：居中主纸、完整下层纸、独立微动、纸层和桌面投影。
- flower_doodles.gd / flower_ink.gdshader：花头分组、绘画过程、微动和纸洞裁切。
- mouse_companion.gd / contact_shadow.gdshader：实时贴身阴影、跨笔跳跃、禁啃与中断清理。
- pencil_prop.gd / pencil_ink.gdshader / pencil_shadow.gdshader：竖放铅笔、对应区域、轻抖、双层投影。
- paper_interaction.gd / tear_mask.gd / tear_reveal.gdshader / underpaper_notes.gd：合并纸洞、内阴影和缓存笔记页。
- title_ink.gdshader / hand_wobble.gdshader：印迹附着主纸及统一啃穿。
- menu_cursor.gd：复用已有素材，第一帧即显示的菜单指针。
- note_modal.gd：移除胶带装饰，便利贴和退出交互保留。
- 删除已被替代的 menu_decor.gd、paper_ink.gdshader 及其 UID。
- 新增本轮 PNG、对应导入配置、完整提示词、检查脚本和实际运行截图。

新增 pencil 仅是 main_menu 内部组件引用，不改变其他模块接口。game_entry 与 start_requested 的正式剧情入口保持原有方式；退出菜单恢复进入前的画面配置。三个迷宫的建筑、路线、相机、角色机制、体力、道具、圣堂和竞速规则未修改。其他成员的未提交文件保留。
