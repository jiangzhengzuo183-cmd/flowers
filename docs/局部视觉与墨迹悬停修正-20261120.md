# 局部视觉与墨迹悬停修正

本轮直接修改当前项目，保留之前的剧情和视频接入。没有提交、推送或合并Git。

- 左上纸样HUD整体放大12%，点击区域随组件缩放；悬停提示避让范围同步更新。
- 右上删除常态、悬停和按下状态的方块底，保留透明点击区域及键盘焦点描边。所有图标统一为黄色；自动播放使用播放/暂停图标，功能提示仍可通过悬停查看。原PNG图标不重绘，运行时统一金黄色笔画并隐藏白色贴纸边。
