# UI 与剧情呈现修正 · 2026-11-20

修改应用于正式仓库 `flowers-team-chapter1`，当前分支 `feature/chapter1-interaction`。已重新导出 `godot/exports/web`。没有提交、推送、合并或发布。

## 本次修改

- 单人查理立绘在 1600×900 设计画布的 x=800 居中；双人对话恢复原左右位置。
- 实验室的便服查理在右侧朝左、左侧朝右，不重绘图片。
- 3月4日墨迹场景提供明确的“罗夏测试 · 观察墨迹卡片”入口，复用已有四卡原生交互及完成回调；退出、重复进入和剧情历史均已检查。
- 金色夹子保留原 PNG、大小与倾斜，在对话框局部坐标 (18,-49) 放置。夹柄在纸外、夹口跨过白纸上沿，避开姓名纸签和正文。保留已有白纸、背纸、姓名纸签、夹子的绘制层级。
- 左上角合并为复古纸张任务 HUD，在 1920×1080 下对应约 360×90，距左上约65px。使用项目思源黑体；地点、目标与完成状态读取现有剧情数据。支持点击折叠、新目标自动展开与280ms轻提示、完成勾选及240ms文字淡化。较长任务自动换行并增加必要高度。
- 面包店背景、人物素材、对话纸张尺寸样式、右上按钮及剧情完成条件保持原有实现。

实际界面是 Godot Control 绘制到网页 Canvas，没有可调整的对话框 HTML/CSS；本次使用父容器局部坐标、z_index 和 clip_contents 达到相同定位与遮挡效果。
