# 迷宫 01：地图数据说明

## 文件
- `maze_01.json`：完整地图墙体矩阵、格子墙体标记、入口出口、检查点和两条路线。
- `maze_01_preview.png`：根据墙体矩阵重新绘制的清晰预览图。

## 坐标约定
- 地图为 **19 行 × 19 列**。
- 所有格子坐标均为 `[row, col]`。
- 原点位于左上角；row 向下增加，col 向右增加。
- 起点：`[18, 0]`，从西侧（west）进入。
- 出口：`[0, 18]`，从北侧（north）离开。
- `true` 表示该边界有墙，`false` 表示该边界可通行。

## 墙体矩阵
- `verticalWalls`：尺寸 `19 × 20`。`verticalWalls[r][c]` 表示第 r 行在第 c 条竖向边界上的墙。
- `horizontalWalls`：尺寸 `20 × 19`。`horizontalWalls[r][c]` 表示第 r 条横向边界在第 c 列上的墙。
- `cellWalls[r][c]` 提供每个格子的 `north/east/south/west` 四面墙，方便直接读取；它由上述两个矩阵派生。

## Three.js / 3D 坐标建议
建议世界坐标：
- x 向右，z 向下，y 向上。
- 每格边长 `cellSizeWorld = 2.4`。
- 格子中心：`x = (col + 0.5) * cellSizeWorld`，`z = (row + 0.5) * cellSizeWorld`。
- 竖向墙段中心：`x = boundaryCol * cellSizeWorld`，`z = (row + 0.5) * cellSizeWorld`，长度为一个格子边长。
- 横向墙段中心：`x = (col + 0.5) * cellSizeWorld`，`z = boundaryRow * cellSizeWorld`，长度为一个格子边长。
- y 方向用于墙体高度。建议先用墙高 3.2、厚度 0.3 作为灰盒默认值，后续可调整。

## 路线
- Route A（绿色）：60 次格子移动，61 个格子坐标。
- Route B（紫色）：92 次格子移动，93 个格子坐标。
- 两条标注路线共用 19 条通行边。
- 路线数组中的每个相邻坐标均为上下左右相邻，并已通过墙体矩阵验证。

## 验证结果
- 全部 361 个格子均可从入口到达。
- 可通行的内部相邻连接：380。
- 墙体边段总数（含外边界）：378。
- 独立回环数（cycle rank）：20。
- 绿色路线合法：True。
- 紫色路线合法：True。
- 最短通路长度：60 步；最短路径数量：1。

**重要：这张地图不只有两条数学意义上的可行路线。** 墙体网络含有多个回环，玩家可以探索出其他路径。A/B 是图中明确标注的两条设计路线，不应将其描述为“全迷宫仅有两种解”。
